\# Week 10 - Inventory Analytics Dashboard



\## Objective

Built a Streamlit dashboard for inventory, shrinkage, data integrity and operational risk analysis.



\## Datasets Used

\- data\_integrity\_report.csv

\- data\_integrity\_summary.csv

\- inventory\_movement\_anomalies.csv

\- operational\_risk\_monitoring.csv

\- stock\_shrinkage\_analysis.csv



\## Dashboard Features

\- Dataset selection

\- Total rows and columns

\- Missing values count

\- Data preview

\- Column summary



\## Technologies

\- Python

\- Pandas

\- Streamlit

python -m streamlit run week-10\\dashboard\\inventory\_dashboard.py
